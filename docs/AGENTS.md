# AGENTS.md

Дата актуальности: 2026-08-29

## Scope

Этот файл относится к каталогу `docs/`.

## Правила документации

- Документация должна отражать текущее фактическое состояние репозитория.
- Команды в документации должны быть runnable из корня проекта.
- После изменения путей, имён файлов, команд запуска, dashboards, метрик или структуры репозитория ссылки и примеры надо обновлять сразу.
- Не дублировать длинные архитектурные объяснения в нескольких файлах без необходимости.

## Структура документации

- `docs/architecture/`
  - инженерные принципы и архитектура решения.
- `docs/monitoring/`
  - мониторинг, Grafana, Prometheus, debugging.
- `docs/runbooks/`
  - пошаговые инструкции запуска и эксплуатации.
- `docs/mvp/`
  - спецификации и результаты инкрементов.

## Правила содержания

- В runbook-файлах приоритет у практических шагов: что запускать, куда смотреть, как интерпретировать.
- В architectural docs приоритет у причин, trade-offs и ограничений.
- В monitoring docs приоритет у метрик, dashboards, PromQL и диагностических сценариев.
- В MVP docs после каждого этапа должен быть явный business value.

## Обязательные обновления

После изменения:

- путей файлов;
- команд в `tools/scripts`;
- расположения dashboards/prometheus config;
- имен документов;

нужно проверить и обновить:

- `README.md`
- `docs/README.md`
- связанные runbook-файлы

## Проверка

После заметных изменений в `docs/` нужно хотя бы вручную проверить:

- что ссылки указывают на существующие файлы;
- что команды соответствуют текущей структуре репозитория;
- что названия документов согласованы с `docs/README.md`.
